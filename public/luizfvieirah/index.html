Sobre

Comecei no back-end de uma fintech: foram 2 anos e 8 meses na Sinqia com Java e SQL Server em produção, entre stored procedures, índices, tuning de queries e incidentes resolvidos direto com os clientes. Foi lá que destravei uma esteira de crédito parada por deadlock e acelerei um relatório de inadimplência que levava minutos.

Em 2022, escolhi me tornar full-stack: fiz freelas em TypeScript e Next.js e, em 2026, lancei o FolioBy, SaaS de portfólio com assinatura recorrente. Agora volto ao back-end Java no domínio financeiro com o WorkFlow Crédito, uma esteira de crédito em Java 21 e Spring Boot 3.

Procuro uma vaga back-end Java ou full-stack, remota, híbrida ou presencial. Falo português (nativo) e inglês fluente, além de espanhol e italiano para conversação do dia a dia.

Projetos

  1. 2026 — hoje

    WorkFlow CréditoBack-end de esteira de crédito · Java 21 e Spring Boot 3

    • Escrevi à mão a máquina de estados de 6 status (enum com as transições permitidas), com motivo obrigatório para reprovar e para cancelar.
    • Isolei o domínio em Java puro, sem anotação de framework (arquitetura hexagonal): troquei o repositório em memória pelo JPA com um adaptador novo; no domínio, só entrou a fábrica Proposta.reconstituir, para recriar a proposta a partir do banco.
    • Criei um scalar GraphQL Decimal próprio para que dinheiro nunca passe por ponto flutuante.
    • Versionei o PostgreSQL com Flyway em SQL puro, com constraints CHECK que espelham as regras do domínio.
    • Cobri o projeto com 74 testes (JUnit 5 e AssertJ), incluindo integração com Testcontainers no GitHub Actions.
    • Próximos passos: padrão Outbox com Kafka, Docker Compose e Spring Cloud Gateway.
